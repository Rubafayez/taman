# تأمن | Ta'man

منصة للمفقودات والموجودات داخل الحرم الجامعي في جامعة الملك سعود: من فقد شيئاً ينشر بلاغاً، ومن وجد شيئاً ينشره، والمنصة تطابق بينهما.

**الموقع:** https://tamanrksu.netlify.app

## الذكاء الاصطناعي

- **صوّر وانشر:** تصوّر الغرض فيُعبّأ البلاغ تلقائياً (النوع والوصف) من الصورة.
- **المطابقة الدلالية:** يُحسب تضمين (embedding) لوصف كل بلاغ لمطابقة المفقود بالموجود حتى لو اختلفت الصياغة.
- **تقييم إجابة التحقق:** تقييم مساند لإجابة من يطالب بالغرض على سؤال التحقق. القرار النهائي لصاحب البلاغ.

## التقنيات

React 19، TypeScript، Tailwind CSS 4، Vite، Supabase، `@google/genai` (Gemini)، Netlify Functions.

## التشغيل محلياً

```bash
npm install
npm run dev
```

يحتاج ملف `.env.local` فيه `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
سياسات قاعدة البيانات في `supabase_rls_policies.sql`.

## النشر

المشروع مهيأ لـ Netlify. طلبات الذكاء الاصطناعي تمر من دالة في الخادم (`netlify/functions/gemini.ts`)، فمفتاح Gemini لا يصل إلى المتصفح. أضف `GEMINI_API_KEY` في متغيرات البيئة للموقع.
